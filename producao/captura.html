Novo fluxo sem API paga: envie a foto no ChatGPT, receba o arquivo JSON produzido a partir da imagem e importe esse arquivo aqui. O sistema monta o dashboard para aprovação, sem enviar fotos para a API nem consumir saldo OpenAI. Almoço: 12h. Fim regular: 21h (horário posterior escrito vale). Horário de fim ausente vira observação; nunca é inventado.
